AI Shift Management & Payroll Platform

A comprehensive multi-tenant workforce management platform designed for businesses with multiple store locations. The system features AI-assisted scheduling, geo-fenced attendance tracking, and automated payroll processing with production-ready backend architecture.

Independent Project
3 Months Development
Full-Stack Implementation

Multi-Tenant Architecture

Designed for multiple stores with isolated data and role-based access control for different user types.

AI-Assisted Scheduling

Intelligent shift scheduling that automatically fills understaffed shifts and detects conflicts.

Geo-Fenced Clocking

Location-based clock-in/out with out-of-zone tracking and manager approval workflows.

Automated Payroll

Smart payroll logic separating per-store hours with accurate combined totals and reporting.

Python / Django
Flutter Mobile App

Implementation Details

Backend Architecture: Built with Django REST Framework featuring role-based authentication, multi-tenant database design with schema separation, and scheduled tasks for automated payroll processing.

Frontend Implementation: Flutter mobile application with provider state management, custom calendar widgets for scheduling, and real-time updates via WebSocket connections.

Key Features Implemented:

  • Fixed weekly scheduling (Friday–Thursday) with automatic locking
  • Immutable audit history for all schedule changes and payroll adjustments
  • Manager and employee mobile apps with different permission levels
  • Automated overtime detection and risk flagging
  • Real-time notifications for schedule changes
